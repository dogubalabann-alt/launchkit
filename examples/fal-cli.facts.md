Source: fal docs (fal.ai/docs), "Installation & Setup" and "Quick Start".

- The fal CLI is for fal Serverless: writing, testing and deploying your own Python apps and models on fal GPUs.
- Install: `pip install fal` (Python 3.8+; macOS, Linux, Windows). Check with `fal --version`.
- Log in: `fal auth login` (opens the browser), or set `FAL_KEY`.
- Test an app with `fal run`, ship it with `fal deploy`.
- Deployed apps get persistent URLs and scale automatically, including scale to zero.
- Serverless is billed per second.
- Serverless access is approved per account: request it at https://fal.ai/dashboard/serverless-get-started
- Docs: https://fal.ai/docs
